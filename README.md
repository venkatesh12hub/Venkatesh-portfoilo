# Venkatesh Portfolio

Responsive portfolio built using:

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- IntersectionObserver

## Run

Open `index.html` directly in a browser. Tailwind CSS is loaded from its CDN for
the existing utility classes.

For VS Code, Live Server is recommended.

## Personalize

1. Keep your resume at `Resume (1).pdf` or update the "View Resume" link in `index.html`.
2. Replace `images/me.jpg` to update the profile photo.
3. Keep the resume details, contact methods, and social links in `index.html` current.

The light/dark mode selection is saved in the browser. Sections and cards use
responsive CSS Grid layouts, and reveal effects use IntersectionObserver.
